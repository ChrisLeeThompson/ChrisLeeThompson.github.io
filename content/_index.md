Welcome to Chris Thompson's GitHub Page!

The title of the page is a nod to the old internet days where we had such titles (along with GIFs of flames and site visit counters).

This page is intended to be a simple way to share Python scripts that I've developed over the last few years while learning Python. Recently, with the use of Anthropic's Claude, it is has been possible to make rapid changes to the original scripts and build new ones. Perhaps the use of LLMs isn't the best choice, but LLMs can be helpful for prototyping as well as learning more about programming.
