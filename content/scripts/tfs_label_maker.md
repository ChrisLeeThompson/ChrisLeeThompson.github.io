## Introduction

The TFS Label Maker is a Python UI that can read the metadata in `.tif` and `.png` images generated by a Thermo Fisher Scientific (TFS) SEM-FIB microscope. Selected metadata populates a customizable label that can be exported as an `.svg` file, burned into a copy of the original image, or both. Single images or batches of images can be processed.

The UI is intended for situations where you want to show more information about an image than is included in its databar (when one is present), or to organize many images based on their metadata.

In addition, the image, with or without its label, can be exported to an active PowerPoint presentation. This can be especially helpful when processing many images for a presentation.

{{< callout type="info" >}}
Exporting images and labels to an active PowerPoint presentation is not supported on MacOS.
{{< /callout >}}

## Requirements

The script's requirements differ from the standard list under [Requirements](/scripts/#requirements) on the [Scripts](/scripts/) page. It requires:

* PySide6 6.7.1+
* Python 3.11+
* tifffile 2025.3.13+
* Pillow 10.1+
* NumPy 2.2.5+
* pywin32 306+ (Windows only; needed for the PowerPoint export)

AutoScript is not required to run this script, but all of these packages are included with the AutoScript 4.14 environment, so no additional dependencies are needed there.

## Installation

To install, follow the general steps under [Installing A Script](/scripts/#installing-a-script) on the [Scripts](/scripts/) page. The script does not connect to a microscope, so it can be installed on any compatible PC.

## Running the Script

The script's main file is `tfs_label_maker.py`. See [Running A Script](/scripts/#running-a-script) on the [Scripts](/scripts/) page for how to run it with the AutoScript Python interpreter or the AutoScript Runner application.

## Loading Images

{{< img src="/tfs_label_maker/tfs_label_maker_1.png" caption="The TFS Label Maker window before images are loaded." alt="TFS Label Maker window" width="90%" >}}

There are two ways to load an image or a batch of images: drag and drop them onto Catbug (the icon in the upper-right corner of the window), or click the Load button and select them.

{{< img src="/tfs_label_maker/tfs_label_maker_2.png" caption="The TFS Label Maker window after images are loaded and the label is populated with metadata." alt="TFS Label Maker with loaded images" width="90%" >}}

The Clear button removes all loaded images. The Stop button stops loading or exporting images and labels. The Start button starts the label and/or image export process. All labels and images are saved to a timestamped `labelled_images` directory in the script root.

## The Label Preview Panel

{{< img src="/tfs_label_maker/tfs_label_maker_label-preview_1.png" caption="The Label Preview panel with four images loaded." alt="TFS Label Maker Label Preview panel" width="90%" >}}

The Label Preview panel shows a preview of the label for each image.

The Previous and Next buttons step through the labels of the loaded images, and the combobox between them can be used to select an image. The cells in the label are populated by selecting metadata from the Metadata panel.

{{< img src="/tfs_label_maker/tfs_label_maker_label-preview_2.png" caption="The Label Preview panel with metadata." alt="TFS Label Maker Label Preview panel with metadata" width="90%" >}}

Drag the cells to rearrange them in the label. Remove data from a cell by dragging the cell outside of the label.

Double-click a cell to add custom text. In the example above, the last cell contains "Custom text...".

## The Metadata Panel

{{< img src="/tfs_label_maker/tfs_label_maker_metadata_1.png" caption="The Metadata panel." alt="TFS Label Maker Metadata panel" width="90%" >}}

The Metadata panel displays the metadata available in the loaded image. Each parameter has a checkbox. Check a checkbox to add the parameter and value to the label. Uncheck the checkbox to remove the parameter and value from the label.

The selected metadata is remembered while the application is open, even when no images are loaded. For example, if you load a batch of images and select metadata parameters, then clear the images and load another batch, the previously selected parameters are pre-selected and populate the label.

## The Output Panel

{{< img src="/tfs_label_maker/tfs_label_maker_output_1.png" caption="The Output panel." alt="TFS Label Maker Output panel" width="50%" >}}

The Output panel contains the options and settings for exporting the labels and/or images.

The Output combobox has the following options for exporting the images and labels:

1. Watermarked images:
    * Copies of the original images are exported with the labels burned in (watermarked).
2. SVG labels:
    * Labels are exported as `.svg` files.
3. Both:
    * Watermarked images and `.svg` files are exported.
4. PowerPoint Only:
    * Images are exported to an active PowerPoint (PPT) presentation. A new slide is created for each image. This option is discussed more in the next section.

Sending the images to an active PPT is possible with any output option: check the Send to active PPT checkbox. The checkbox is disabled when PowerPoint Only is selected because that option always sends to PPT.

### Sending to PowerPoint

The PowerPoint Only output option can be used to export images and labels to an active PPT presentation.

There are four settings associated with sending the images to PPT.

1. Transition slide:
    * If your PPT template has a transition slide, then you can specify its slide index, and it will be create above all exported slides.
2. Image slide:
    * If your PPT template has a specific image slide, then you can specify the index for the image slide you want to use when sending images to PPT.
    * If the index is not found, then a new, generic slide will be used for the image.
3. Send to active PPT:
    * This checkbox is available for all output options.
4. Add label object:
    * Check this option to send the label as a PPT object. This can be helpful if you do not want the images to be watermarked with the label or you want full control of the label in PPT.

For each slide, the image filename is saved to the slide's notes. When sending a batch of images to PPT, the images are added chronologically from oldest to newest. For example, the first image acquired will be at the top of the slide deck and the last image acquired will be at the bottom of the deck.

{{< callout type="info" >}}
You do not have to send a label with the images. If the label is empty, then only the images are sent to PPT. This is an easy way to add many images to a presentation.
{{< /callout >}}
