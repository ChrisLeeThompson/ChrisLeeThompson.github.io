{{- /* Project shortcode: N side-by-side columns of markdown. Exists because Hextra ships no multi-column layout. `cards` is a link component -- every cell is an with a border and a hover lift, and `card` never reads its inner content -- and `hextra/feature-grid` hardcodes `not-prose`, which strips paragraph margins, list bullets and link colours from everything inside it. This shortcode is layout only: no colour, no border, no hover, and the page typography inside a column is left completely alone. That is also why it needs no dark-mode rules at all. (The optional `caption` is the one styled piece, and its look -- centred, small, grey, dark-mode aware -- comes from Hextra's own figcaption rule, the same one that styles an `img` caption.) Call it with angle delimiters. Each cell is a nested `column` shortcode, which renders nothing itself and hands its content up through .Parent.Store, exactly as Hextra's tab/tabs pair does. Collecting the cells first is what lets this template check `ratio` against the real column count and catch content left between two `column` blocks -- both silent layout bugs otherwise. Columns reflow on the width of their *container*, not on a viewport breakpoint. On a Hextra docs page the content column is 719px wide at a 767px viewport but only 416px at 768px, because the 16rem sidebar and main's wider padding both switch on at md -- available width is not monotonic in viewport width, so a media query would turn the columns on at the worst possible moment. flex-wrap plus a per-column min-width reflows at the real width, wraps one column at a time when there are three or more, and stays correct if the sidebar or the page width is ever reconfigured. Numbers are emitted as CSS custom properties in an inline `style`, per Hextra's own convention for dynamic values (cf. --hextra-cards-grid-cols in _partials/shortcodes/cards.html), and never as generated Tailwind classes: Hextra ships a prebuilt assets/css/compiled/main.css that Tailwind never scanned for this project, so an unlisted hx: class emits no CSS at all, silently.
